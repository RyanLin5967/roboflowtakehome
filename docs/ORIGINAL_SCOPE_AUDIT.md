## Why this audit exists

On 2026-09-26, the user challenged the statement that the entire original description was finished. Root and two independent auditors compared source and saved evidence with `../roboflow-labs-takehome-research/FINAL_SHORTLIST.md`, `round6/RESEARCH_OUTCOME.md` and `round6/COUNTERPART_INFRA.md`. **The unconditional completion statement was too broad.** The implementation then lacked a frozen detector contract, revised-verifier history, related-session grouping, a comparative feedback-age benchmark, broader visual controls, a review path for machine-refused evidence, and Roboflow annotation/version delivery.

The earlier 752 Python tests, 17 browser tests, container checks and failure probes were real evidence for the features they exercised. They did not establish coverage of omitted requirements. The user subsequently authorized fixing the gaps. The table below supersedes the original “not implemented” findings while retaining the distinction between source coverage, executed tests and external proof.

## Infrastructure already present and retained

The core service includes durable sessions and original media, idempotent submissions, accepted-baseline preservation, scene re-grounding, capture/revision/epoch identity, fenced worker leases, bounded preview coalescing, committed-evidence priority, cross-worker dispatch limits, per-frame checkpoints and conservative durable usage reservations. Campaign admission, scoped invitations, collector recovery, independent review actions and immutable releases complete the collection workflow.

Filesystem and S3-compatible storage are immutable. Lifecycle guards coordinate uploads, cleanup and backups. Operator authentication, production origin/host policy, bounded archives, independent archive validation, container packaging and failure/recovery probes are implemented. The earlier actual isolated container boot, worker kill, complete service restart, compiled mobile UI and byte-preserving download checks remain historical evidence. New-feature HTTPS/container validation must be recorded separately before being claimed for this closure.

The final application-source run passed **1,043 Python tests**, zero skipped, in 82.01 seconds. The adaptive-polling frontend passed **30 browser tests**. Actual capture, product and new evidence/adjudication browser flows passed; downloaded releases validated independently. The 50 benchmark trials and fresh HTTPS container exercise are recorded separately below and in the validation report. Historical migration testing separately reports **7 passing tests** using real archived old implementations and actual PostgreSQL restore. It preserves original rows/releases, rejects unsafe legacy execution, checks failed-migration rollback, and restores every new feature table including baseline authority and delivery uncertainty. See [migration evidence](GAP_MIGRATION_EVIDENCE.md) and the final [validation report](VALIDATION_REPORT.md) for executed results.

## Remaining evidence and intentional limits

- **Physical collection quality and value are unmeasured.** The user deferred the trial. Positive fixed-reference and temporal capture accuracy, useful pairs per capture/reviewer minute, new-scene generalization and a comparison with a competent shot list/simple rules/VLM judge require actual independently labeled attempts. Neither fixtures nor scheduler replay can supply that evidence.
- **Private hosted delivery remains an account limitation.** Generated public test cards are separate transport diagnostics, not permission to export camera images publicly. The public-only account's private-project refusal remains real.
- **External receipts have bounded meanings.** A generation ACK is not content verification. Imported COCO validates membership, partitions and boxes but does not authenticate its origin or prove remote pixel identity. Ambiguous generation remains reserved and is reconciled by reads; it is never blindly resubmitted.
- **The visual scope is deliberately observable and bounded.** Two recipe families, distinct supported classes, 2-D registration, appearance checks and declared protected objects do not imply arbitrary recipes, physical instance identity, all scene changes or unseen action timing. Engineering thresholds still need real collection calibration.
- **Hosted deployment evidence is separate.** The original local container deployment passed; hosted S3 compatibility, public DNS/TLS issuance and remote CI were not established by that test. The final local HTTPS image, generated-card Roboflow version and Modal public-photo probe now passed their disclosed gates; see their reports. None establishes public hosting or physical collection quality.
- Custom training, downstream VLM improvements, marketplace/payouts, an automatic physical-action optimizer, arbitrary rule authoring, Kubernetes, WebRTC and microbatching were optional or not promised in the selected build. Their absence is not an omitted required mechanism. Simple campaign quotas/progress exist; automatic condition-based work allocation remains optional.

A source-complete mechanism, a tested implementation, an actual provider round trip, and a demonstrated benefit to collectors are four different claims. This record keeps them separate so the earlier overstatement is not repeated.
